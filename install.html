Cardiology Residents

Install the training portal on your phone with the new Cardiology Residents app identity.

Install on iPhone or iPad

Use Safari to add Cardiology Residents directly to your Home Screen.

  1. Tap Share.
  2. Choose Add to Home Screen.
  3. Keep Open as Web App ON.
  4. Confirm the metallic-heart / red ECG icon and tap Add.
If you are viewing this page inside WhatsApp, Facebook, or another in-app browser, first choose Open in Safari.

Install on Android

Download the current production-signed Cardiology Residents APK.

Download Android app
Android may ask you to allow installation from your browser the first time.
