Cardiology Residents

This clean installer uses one iPhone web-app identity and a new uncached RGB Home Screen icon path.

Install from Safari
  1. Open this page in Safari.
  2. Tap Share.
  3. Choose Add to Home Screen.
  4. Keep Open as Web App ON.
  5. Check that the Cardiology Residents logo is visible, then tap Add.
The installed icon opens the normal Cardiology Residents login portal and uses the same live account and data.
You appear to be in a browser other than Safari. For the most reliable iPhone install, use Share → Open in Safari first.
