Cardiology Residents

Install Cardiology Residents on your iPhone as a Home Screen web app.

Add from Safari
  1. Open this page in Safari.
  2. Tap Share → Add to Home Screen.
  3. Leave Open as Web App ON.
  4. Confirm the new navy metallic-heart / red ECG icon, then tap Add.
When launched from the Home Screen, the icon opens the normal Cardiology Residents login portal automatically.
