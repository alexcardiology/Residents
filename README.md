# Cardiology Resident Training & Assessment
Invitation-only GitHub Pages + Supabase platform with Resident, Observer, Assessor and Owner portals. See `SETUP_GUIDE.md`.

Pass thresholds: Knowledge 6/10, Skills 7/10, Attitude 8/10, Total 21/30. Every threshold must be passed. Failure schedules reassessment after two months; passing makes the resident eligible for owner-confirmed upgrade.
